3. Live points leaderboard
RankDriverStagesTotalStatus
Overall ranking: highest net points wins. FINISH and DNF net points cannot fall below the minimum Gate-1 score (round(DNF base / total gates)). DNF net = max(Gate-1 minimum, round(DNF base x gates cleared / total gates) minus point penalties). DNS = 0. If stage points tie, FINISH ranks above DNF. Overall tie-break: more FINISH results, higher SS4 net points, lower total raw time across FINISH stages, then lower race number. DNF base is frozen at the first official result; later entries do not change it. Gate totals lock after the first saved result in that SS.
4. Penalty Setup
Same rules for every SS

Configure each penalty type and its point deduction before racing. These shared rules apply to every SS. Edit these shared rules when no run is active. Roll Over applies only when the crawler comes to a complete stop with all four tyres lifted off the ground; a brief bounce or momentary lift while still moving does not count. Each tap deducts the configured number of points from that stage score; it does not add time or change the raw-time finishing order. Values are frozen when a tap is recorded, so editing a rule affects future taps only. Removing a rule does not erase penalties already recorded.
